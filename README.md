## 📌 Featured Projects

### StudyMind AI
Technologies: React • Express.js • TypeScript • Tailwind CSS • Vite • Gemini API

- Built a full-stack learning assistant that converts study notes into AI-generated flashcards and 4-option quizzes using the Gemini API.
- Implemented schema-validated JSON generation, exact item-count enforcement, and retry logic with exponential backoff to generate 200+ quizzes from 100+ note documents.
- Added request timeouts, stale-request cancellation, per-IP rate limiting, Helmet headers, restricted CORS, and secure backend API key handling for production-readiness.

### DDoS Sentinel: Real-Time Threat Intelligence Dashboard
Technologies: React • FastAPI • Python • REST APIs • GeoLite2 • AbuseIPDB

- Worked in a 4-member Agile team to implement heuristic threat scoring, GeoIP mapping, and interactive analytics.
- Built scheduled polling pipelines to monitor severity trends and attack activity in real time.

### AI Resume Parser & Job Matching System
Technologies: React • Node.js • Python • MySQL • Gemini API

- Built a full-stack AI resume parser and job-matching platform using React, Node.js, Python, MySQL, and Gemini API.

- Integrated frontend and backend services to automate resume processing and AI-driven job matching.

### Report Genie AI
